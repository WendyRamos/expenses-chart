# 📊 Expenses Chart

Solución al desafío **Expenses Chart** de [Frontend Mentor](https://www.frontendmentor.io/).

El proyecto consiste en recrear una interfaz de seguimiento de gastos semanales, mostrando los valores mediante un gráfico de barras y adaptando el diseño para diferentes tamaños de pantalla.

## 🚀 Demo

🔗 **[Ver proyecto en vivo](https://expenses-chart.vercel.app)**

## 🛠️ Tecnologías utilizadas

* HTML5
* CSS3
* React
* Diseño responsive

## 📌 Características

* Gráfico de gastos semanales.
* Representación visual de los datos mediante barras.
* Identificación del día con mayor gasto.
* Diseño responsive para dispositivos móviles y escritorio.
* Interacción visual al pasar el cursor sobre las barras.

## 🎯 Objetivo del proyecto

Este desafío fue realizado para practicar:

* Maquetación de interfaces a partir de un diseño.
* Uso de **HTML semántico**.
* Creación de layouts responsive con CSS.
* Manipulación y representación de datos con React.
* Atención a detalles visuales y adaptación del diseño a diferentes resoluciones.

## 💡 Aprendizajes

Durante el desarrollo reforcé la forma de transformar un diseño visual en una interfaz funcional, especialmente en la construcción del gráfico, el manejo de los datos y la adaptación responsive.
